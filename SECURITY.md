# Política de seguridad

Si encuentras una vulnerabilidad en UNITECA, **no abras un issue público**.

Repórtala de forma privada desde la pestaña **Security → Report a vulnerability** de este repositorio.
Incluye, si puedes, los pasos para reproducirla y el impacto que tiene.

El equipo la revisará lo antes posible y te avisará cuando esté corregida.
